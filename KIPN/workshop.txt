title=KIP Network Terminal
description=[h1]The Knox County Information and Property Network (KIPN)[/h1]
description=
description=KIPN turns in-world computers into functional network terminals for Project Zomboid Build 42 multiplayer servers.
description=
description=Players can use physical computers to access accounts, server statistics, weather forecasts, announcements, administration tools, and any optional KIPN services installed by the server.
description=
description=The Terminal works as a standalone mod. It also provides the shared foundation used by every additional KIPN module.
description=
description=[h2]Why Run KIPN?[/h2]
description=
description=KIPN connects server features to actual places in the world.
description=
description=Instead of accessing everything through abstract menus, players must find and use computers inside the correct locations. A computer in a government office may provide property services, while one inside a dealership may handle vehicle ownership.
description=
description=This structure gives server owners a foundation for:
description=
description=[list]
description=[*]Player-run businesses and professions
description=[*]Property and vehicle ownership
description=[*]Government and administrative services
description=[*]Physical mail and item delivery
description=[*]Location-based rules and permissions
description=[*]Economies, roleplay, and long-term server progression
description=[/list]
description=
description=[h2]Included with KIP Network Terminal[/h2]
description=
description=[list]
description=[*][b]Functional Computers[/b] - Turn in-world computers into interactive KIPN terminals
description=[*][b]Player Accounts[/b] - Players can register, sign in, and access services through their own accounts
description=[*][b]World Registry[/b] - Admin-created zones determine which services are available at each computer
description=[*][b]Server Statistics[/b] - Player and server-wide statistics with leaderboards for survival time, zombie kills, PvP kills, and more
description=[*][b]Widgets[/b] - Seven-day weather forecast and time-and-date displays
description=[*][b]Computer Overhaul[/b] - Power, condition, boot sequences, repair, dismantling, sounds, lighting, and randomized connection speeds
description=[*][b]Administration Tools[/b] - Permission controls, configuration tools, logging, and support for additional KIPN modules
description=[/list]
description=
description=[h2]World Registry[/h2]
description=
description=A computer's [b]location[/b] determines what it can do.
description=
description=Server administrators draw and manage World Registry Zones with the in-game Zone Editor. Computers automatically display the services assigned to the zone containing them.
description=
description=Move a computer into a different zone and its available services change with its new location.
description=
description=[list]
description=[*][b]Custom Zones[/b] provide flexible locations for server-defined uses
description=[*][b]Do Not Claim Zones[/b] prevent players from claiming protected areas
description=[*]Optional KIPN modules automatically register their own zone types
description=[*]Examples include Government Service, Vehicle Dealership, and Post Office Zones
description=[/list]
description=
description=[h2]Computer Glow Up[/h2]
description=
description=KIPN computers feel like physical machines instead of simple menu buttons.
description=
description=[list]
description=[*]Computers must be powered before they can be used
description=[*]Computer Condition naturally degrades through time and use
description=[*]Starting quality can be configured as Good, Normal, or Bad
description=[*]Players can repair damaged computers using Electrical skill
description=[*]Dismantling damages the computer instead of immediately destroying it
description=[*]Randomized connection speeds control how quickly terminal pages load
description=[*]Powered computers produce light
description=[*]Computers feature power-up, operating, condition-based, and shutdown sounds
description=[/list]
description=
description=[h2]Optional KIPN Service Modules[/h2]
description=
description=Additional KIPN modules expand the Terminal with new services, items, zones, and server systems. Installed modules register themselves automatically and appear on computers in the appropriate locations.
description=
description=[h3]KIPN Government Services[/h3]
description=
description=Adds a token-based property ownership system.
description=
description=[list]
description=[*]Claim safehouses and land through a multi-step crafting process
description=[*]Claim any valid building outside protected KIPN zones
description=[*]Configure claim boundaries, trespass rules, and respawn permissions
description=[*]View and release owned properties through KIPN terminals
description=[/list]
description=
description=[h3]KIPN Vehicle Services[/h3]
description=
description=Adds a token-based vehicle ownership system.
description=
description=[list]
description=[*]Craft Registration Forms and process them into Vehicle Titles
description=[*]Require players to travel to a Dealership Zone to claim vehicles
description=[*]Allow admins to turn any suitable location into a dealership
description=[*]Configure access rules for passengers, mechanics, towing, doors, and windows
description=[/list]
description=
description=[h3]KIPN Postal Service[/h3]
description=
description=Adds physical mailboxes and secure item delivery.
description=
description=[list]
description=[*]Deliver marketplace purchases and prize items to PO Boxes
description=[*]Allow admins to establish Post Offices anywhere in the world
description=[*]Offer Small, Medium, and Large PO Boxes with configurable capacities and prices
description=[*]Require physical KIPN-issued keys to access each PO Box
description=[*]Allow keys to be copied, traded, lost, or stolen
description=[/list]
description=
description=Optional modules are available from the links section of this Workshop page.
description=
description=[h2]Accounts and Administration[/h2]
description=
description=[list]
description=[*]KIPN permissions derive from existing Project Zomboid access levels
description=[*]Additional KIPN administrators can be assigned through sandbox settings
description=[*]The server validates all privileged actions
description=[*]Administrative and security events are written to the KIPN audit log
description=[/list]
description=
description=KIPN is server-authoritative. Players request actions through the terminal, but validation, data storage, permissions, and protected changes are handled by the server.
description=
description=[b]Server-level configuration changes require a server restart.[/b]
description=
description=[h2]For KIP Network Module Developers[/h2]
description=
description=KIP Network Terminal provides shared infrastructure for third-party service modules. Developers can build new services without recreating KIPN's terminal interface, accounts, permissions, World Registry, administration, or server communication systems.
description=
description=The service-module registration contract is documented in [b]README-SERVICE-API.md[/b].
description=
