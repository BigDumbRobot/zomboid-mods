title=Careers Framework
description=[h1]Careers Framework[/h1]
description=A server-authoritative framework for building player-run careers on the [b]Knox County Information and Property Network[/b] (KIPN). It adds no playable career by itself -- install one or more career mods built on it.
description=
description=[h2]What the framework provides[/h2]
description=[list]
description=[*][b]Shared currency[/b] - one admin-configured currency item and value used by every career for licenses, escrow and payouts (fallback Base.Money)
description=[*][b]Career Services zones[/b] - an admin-drawn zone type; terminals inside it can issue career licenses
description=[*][b]Business flyers[/b] - one shared flyer item every career's advertising re-uses
description=[*][b]Storefront registry[/b] - every installed career's shops are checked against each other, so businesses from different careers never overlap
description=[*][b]No Claim and safehouse checks[/b] for storefront establishment
description=[/list]
description=
description=[h2]Careers built on this framework[/h2]
description=[list]
description=[*]Careers: Drug Dealer
description=[*]Careers: Mechanic
description=[*]Careers: Blacksmith
description=[/list]
description=
description=Requires KIPN. Load order: KIPN, Careers Framework, then any career mods.
